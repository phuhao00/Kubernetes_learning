# M1 · 需求范围确认

> **项目性质**：个人实践 · 模拟企业流程  
> **角色**：一人兼任 PO / PM / 开发  
> **模拟排期**：第 1 周（2026-09-01 ~ 2026-09-05）

## 项目背景

为 IT 项目经理求职作品集构建一个**可点击运行**的 AI 客服 Demo，配套真实 PM 交付物，证明「能定范围、能排期、能验收、能复盘」——而非纯 Excel 文档。

## In Scope（M1 确认纳入）

| # | 能力 | 说明 |
|---|------|------|
| 1 | 用户对话界面 | 左侧聊天，发送问题并展示回复 |
| 2 | 知识库管理 | 右侧 FAQ 增删改查、启用/禁用 |
| 3 | FAQ 导入 | CSV 上传 + 文本粘贴 |
| 4 | 智能检索 | 关键词 + 简单相似度匹配 |
| 5 | 转人工兜底 | 未命中时明确提示 + 记录待处理列表 |
| 6 | 可选 LLM 润色 | 有 API Key 时润色回答；无则检索直答 |
| 7 | PM 交付物 | 范围/WBS/甘特/RAID/变更/周报/Dashboard/验收 |

## Out of Scope（明确排除）

- 用户登录 / 权限 / 多租户
- 真实人工坐席工作台（仅记录队列）
- 向量数据库 / Embedding 服务
- 生产级部署（K8s、监控、灰度）
- 8 人团队 RACI、EVM、20 页 PPT

## 用户故事 & 验收标准

### US-01 用户提问并获得 FAQ 回答

**作为** 终端用户，**我希望** 输入常见问题后快速得到准确回答，**以便** 自助解决问题。

| 验收标准 | 可测试 |
|----------|--------|
| 输入与种子 FAQ 语义相近的问题，3 秒内返回相关答案 | ✓ |
| 回复区域标注是否命中知识库 | ✓ |
| 禁用状态的 FAQ 不参与检索 | ✓ |

### US-02 未命中问题转人工

**作为** 用户，**我希望** 机器人答不上时被告知转人工，**以便** 知道后续有人跟进。

| 验收标准 | 可测试 |
|----------|--------|
| 完全无关问题返回明确「转人工」文案 | ✓ |
| 该问题写入「待人工处理」列表并带时间戳 | ✓ |

### US-03 管理员维护知识库

**作为** 知识库管理员，**我希望** 增删改查 FAQ 并控制启用状态，**以便** 保持知识时效。

| 验收标准 | 可测试 |
|----------|--------|
| 可新增、编辑、删除、启用/禁用 FAQ | ✓ |
| 列表实时刷新 | ✓ |

### US-04 批量导入 FAQ

**作为** 管理员，**我希望** 通过 CSV 批量导入，**以便** 快速初始化知识库。

| 验收标准 | 可测试 |
|----------|--------|
| 支持 `.csv` 文件上传（question, answer, keywords） | ✓ |
| 支持粘贴 CSV 文本导入 | ✓ |
| 导入后可被检索命中 | ✓ |

### US-05 可选 LLM 增强（Nice-to-have → M3 纳入）

**作为** 产品负责人，**我希望** 在配置 API Key 后回答更自然，**以便** 展示 AI 能力；未配置时 Demo 仍可用。

| 验收标准 | 可测试 |
|----------|--------|
| 无 Key 时检索直答，不报错 | ✓ |
| 有 Key 时回答经过润色且不改事实 | ✓ |
| LLM 调用失败自动回退 | ✓ |

### US-06 项目 PM 交付物

**作为** 求职者，**我希望** 有完整 PM 文档与可运行 Demo 互证，**以便** 面试时讲故事。

| 验收标准 | 可测试 |
|----------|--------|
| pm/ 目录含 WBS、甘特、RAID、变更、周报、Dashboard | ✓ |
| 三场景验收清单可执行 | ✓ |
